# Key Features

1. **Expense Tracking:** Daily income and expense tracking
2. **Smart Budgeting:** AI suggests monthly budget limit
3. **Visual Reports:** Pie charts and bar graphs for spending
4. **AI Chatbot:** Ask doubts like "How much did I spend on food?"
5. **Goal Setting:** Set savings goals for bike, trip, etc.
6. **Alerts:** Warning when you overspend
7. **Secure:** User data is fully secure and private
